# بوت مسابقات الأنمي - واتساب

## 1) المتطلبات
- تثبيت Node.js (نسخة 18 أو أحدث): https://nodejs.org (أو `pkg install nodejs` على Termux)
- رقم واتساب تربطه بالبوت (يفضل رقم غير رئيسي لتفادي أي خطر حظر)

هذا المشروع يستخدم مكتبة **Baileys** (اتصال مباشر بواتساب بدون متصفح)،
عشان يشتغل خفيف وثابت حتى على الجوال عبر Termux.

## 2) التثبيت

### على لابتوب/كمبيوتر (Windows/Mac/Linux)
افتح Terminal داخل مجلد المشروع ونفّذ:
```
npm install
```

### على الجوال عبر Termux
```
pkg update && pkg upgrade
pkg install nodejs git python make clang
cd anime-quiz-bot
npm install
```
(الحزم `python make clang` تحتاجها بعض المكتبات الفرعية لو احتاجت بناء أثناء
التثبيت — لو ما احتجتها npm بيتجاوزها عادي)

## 3) التشغيل
```
npm start
```
بيطلع لك QR code بالطرفية (Terminal). افتح واتساب بجوالك > الأجهزة المرتبطة >
ربط جهاز > امسح الكود. أول مرة بس تحتاج تسوي هذا، بعدها الجلسة تنحفظ تلقائياً
بمجلد `auth_info_baileys` وما يطلب منك تمسح الكود كل مرة.

⚠️ لو شغلته على Termux وسكّرت التطبيق، الجلسة تنقطع. عشان يفضل شغال بالخلفية
استخدم:
```
termux-wake-lock
npm start
```
أو شغله داخل جلسة `tmux`/`screen` عشان يستمر حتى لو قفلت شاشة الجوال.

## 4) حصر البوت بقروب معين (اختياري)
- بأي محادثة (خاص أو قروب) اكتب: `شات الايدي`
- البوت بيرد عليك بآيدي المحادثة (شكله مثلاً `1203xxxxxxxx@g.us`)
- افتح ملف `data/config.json` وضيف الآيدي داخل `allowedChats`:
```json
"allowedChats": ["1203xxxxxxxx@g.us"]
```
- لو تركت `allowedChats` فاضية `[]` البوت يشتغل بأي محادثة يوصله فيها أمر البدء.

## 4.5) تحديد نفسك كمالك (مهم! عشان تقدر تستخدم أوامر .ريسيت)
- بأي محادثة اكتب: `ايديي`
- البوت بيرد عليك بآيديك الشخصي
- افتح `data/config.json` وحط الآيدي بحقل `ownerId`:
```json
"ownerId": "9665xxxxxxx@s.whatsapp.net"
```
- طول ما `ownerId` فاضي، أوامر `.ريسيت توب` و`.ريسيت سجل` **مرفوضة للجميع** (حماية افتراضية)، لازم تحطه أول.

## 4.6) ربط قاعدة بيانات MongoDB (اختياري لكن موصى فيه)
بدون هالخطوة، كل بيانات `.سجل` و`.توب` والتسجيلات تنمسح كل ما تعيد تشغيل
البوت (تبقى بالذاكرة بس). بربطها بـ MongoDB Atlas (مجاني) تصير دائمة.

**تأكد إن حسابك مضبوط صح:**
1. سجّل حساب مجاني على [cloud.mongodb.com](https://cloud.mongodb.com)
2. أنشئ Cluster من نوع **Free (M0)**
3. من "Database Access": أنشئ مستخدم قاعدة بيانات (username + password) — احفظهم
4. من "Network Access": أضف `0.0.0.0/0` (يسمح بالاتصال من أي مكان — مناسب لأن جهازك/سيرفرك ما له IP ثابت)
5. من "Connect" > "Drivers": انسخ رابط الاتصال (Connection String)، شكله تقريباً:
```
mongodb+srv://username:password@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
```
6. استبدل `<password>` برمزك الفعلي (لو موجودة بالرابط كنص حرفي)
7. افتح `data/config.json` وحط الرابط بحقل `mongoUri`:
```json
"mongoUri": "mongodb+srv://username:password@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority"
```
8. شغّل البوت (`npm start`). لو كل شي صح، أول سطر بالـ Terminal بعد التشغيل
   لازم يطلع:
```
✅ اتصل بقاعدة بيانات MongoDB بنجاح.
📥 تحميل 0 سجل نقاط من قاعدة البيانات.
📥 تحميل 0 سجل لوحة صدارة من قاعدة البيانات.
📥 تحميل 0 تسجيل من قاعدة البيانات.
📥 تحميل 0 موقوف و0 محظور من قاعدة البيانات.
```
لو طلع `❌ فشل الاتصال بـ MongoDB` بدل كذا، تأكد من: كتابة الرابط صح
(خصوصاً الرمز السري)، وإن IP مضاف بـ Network Access، وإن المستخدم صلاحياته
كاملة (Read and write to any database).

⚠️ لو ما حطيت `mongoUri`، البوت يشتغل عادي بالذاكرة بس (ما يتوقف)، بس
تفقد البيانات عند إعادة التشغيل.

## 4.7) جلسة واتساب بقاعدة البيانات (تلقائي لو ربطت MongoDB)
لو `mongoUri` مضبوط صح، البوت يخزّن جلسة واتساب (بيانات الربط، بدل ملف
`auth_info_baileys`) داخل MongoDB نفسها تلقائياً — بدون أي إعداد إضافي
منك. هذا يعني إنه حتى لو شغّلت البوت على سيرفر يمسح ملفاته عند كل إعادة
تشغيل (شائع بالاستضافات المجانية)، جلسة واتساب تفضل موجودة ومسحوبة من
القاعدة، وما تحتاج تمسح QR من جديد كل مرة.

لو `mongoUri` فاضي، البوت يرجع تلقائياً للطريقة القديمة (ملف
`auth_info_baileys` محلي) — يشتغل عادي بس محلياً بس.

## 5) الأوامر
القائمة الكاملة والمحدّثة دايماً متوفرة داخل الواتساب بأمر `.ريم اوامر`. أهم الفئات:

| الفئة | أمثلة |
|---|---|
| مسابقات عادية | `.فنش <رقم>`, `.فص <رقم>`, `.فكت <رقم>`, `.فتع <رقم>`, `.فسس <رقم>`, `.انهاء`, `النقاط` |
| مسابقات جوالات بس | نفس الأوامر أعلاه + `ج`: `.فنش ج 50`, `.فص ج 15` ... (الخارجي يُتجاهل تماماً) |
| مسابقات مستمرة (توقف يدوي) | `.مسص`/`.سص`, `.مسس`/`.سس`, `.متع`/`.ستع`, `.مسكت <1-50>`/`.سكت` |
| تقديم بسيط (معاينة، بدون تسجيل) | `.ص`, `.س`, `.تع`, `.كت`, `.كت كلمة`…`.كت خمس كلمات` |
| الترتيب والصدارة | `.توب`, `.توب ص/كت/تع/سس`, `.سجل` |
| خاص بالجوالات | `.تسجيل جوال`, `.تسجيل خارجي`, `.الغاء تسجيل`, `.توب جوالات`, `.توب <نوع> جوال`, `.سجل جوالات` |
| عامة | `شات الايدي`, `ايديي` |
| أوامر صاحب البوت | `.ريسيت توب`, `.ريسيت سجل`, `.ايقاف @شخص`, `.الغاء ايقاف @شخص`, `.حظر @شخص`, `.الغاء حظر @شخص`, `.ازالة @شخص`, `.ازالة تصفير @شخص` |

## 5.5) ملاحظات على الميزات الجديدة
- **التقديم البسيط** (`.ص`/`.كت`/`.تع`/`.س`): جولة وحدة للمعاينة/التجربة، وقتها يُحسب وتُعرض النتيجة، بس **ما تُسجَّل** بـ`.توب` ولا `.سجل` (مو منافسة رسمية).
- **المسابقات المستمرة** (`.مسص`/`.مسس`/`.متع`/`.مسكت`): نفس منطق النقاط والوقت المعتاد، بس ما تتوقف عند أي هدف — تستمر لحد أمر الإيقاف المخصص لها، وعندها تعرض النتيجة النهائية زي أي مسابقة عادية.
- **مسابقات الجوالات بس** (`ج`): أي شخص مو مسجل كـ"جوال" تُتجاهل رسائله بالكامل بهذي المسابقة، حتى لو جاوب صح.
- أي شخص يشارك بمسابقة وما سجل نوع جهازه بعد، البوت يذكّره مرة وحدة بس — تذكير، مو إلزام (إلا بمسابقات الجوالات بس).

## 6) المطابقة مرنة بكل الفقرات
أي إجابة صحيحة تُحسب **بغض النظر** عن:
- وجودها لحالها أو وسط كلام/حروف زيادة بنفس الرسالة ("للل لوفي" ✅)
- وصولها برسالة وحدة أو رسائل متفرقة
- ترتيب وصول العناصر (بالتعداد والكتابة)
- وجود رموز فاصلة زي ~ أو فاصلة عادية بين الإجابات

## 7) كيف تعدّل الأسئلة/الكلمات/التعداد/الصور
كل البيانات موجودة بمجلد `data/` وتقدر تعدلها بأي وقت (حتى والبوت شغال،
التعديلات تنعكس بالجولة الجاية مباشرة بدون إعادة تشغيل):

### أ) `data/words.json` (فقرة الكتابة)
بنك كلمات واحد كبير، كل عنصر فيه:
- `word`: مصفوفة الصيغ المقبولة لنفس الكلمة/الاسم (أول صيغة بالمصفوفة هي
  اللي تنعرض بالسؤال)

```json
{ "word": ["لوفي", "مونكي دي لوفي", "luffy"] }
```

كل جولة كتابة، البوت يسحب عشوائياً **1 إلى 3 كلمات** من البنك (بدون تكرار
بنفس الجلسة إلا لو خلصت القائمة)، ويرسلها بصيغة:
```
✍️ اكتب التالي:

*لوفي* - *زورو* - *نامي*
```
ولازم كل الكلمات تتكتب عشان تفوز بالجولة — بأي رسالة، بأي ترتيب، حتى لو
وسط كلام زيادة أو حروف ملتصقة (مثلاً "للل لوفي" تُحسب "لوفي" عادي).

### ب) `data/counts.json` (فقرة التعداد المستقلة)
كل عنصر فيه:
- `topic`: نص السؤال (مثلاً "عدد 3 شخصيات من ون بيس")
- `required`: عدد الإجابات المطلوبة
- `answers`: مصفوفة، كل عنصر فيها هو مصفوفة صيغ مقبولة لعنصر واحد صحيح
  (مثال: `["لوفي", "luffy"]` تمثل نفس الشخصية)
- `points`: النقاط عند إكمال العدد المطلوب

⚠️ هذي الفقرة **تقبل** إجابات متفرقة بعدة رسائل، ومو لازم نفس الشخص يرسلها
برسالة وحدة. أول شخص يجمع العدد المطلوب من إجابات صحيحة (كل وحدة تُحسب مرة
وحدة بالمجموع، ما تنكرر) يفوز بالجولة.

### ج) `data/questions.json` (فقرة الأسئلة)
نوعين من الأسئلة:
1. **عادي** (`"type": "normal"`): سؤال وجواب واحد، نفس منطق الكتابة (رسالة وحدة).
2. **تعداد** (`"type": "count"`): مثل "الخونة؟" تحتاج عدة أسماء، نفس منطق فقرة
   التعداد (`required` + `answers` بنفس الصيغة).

### د) `data/images.json` + مجلد `data/images/`
- حط الصور جوه `data/images/` (jpg أو png)
- بملف `images.json` كل عنصر يحدد:
  - `file`: اسم ملف الصورة بالضبط (لازم يكون موجود بمجلد images)
  - `question`: نص السؤال (اختياري، الافتراضي "من هذه الشخصية؟")
  - `answers`: الإجابات المقبولة
  - `points`: النقاط

### هـ) `data/config.json`
- `allowedChats`: قائمة المحادثات المسموحة (فاضية = الكل مسموح)
- `nextQuestionDelayMs`: مدة الانتظار قبل إرسال السؤال التالي (بالميلي ثانية، 1000 = ثانية وحدة)

## 8) ملاحظات مهمة
- الأرقام بأسماء المستخدمين بالنقاط والترتيب تُعرض تلقائياً بالمنشن (@)
  لأن هذا يعتمد على واتساب مباشرة ومايحتاج منك أي إعداد إضافي.
- لو حبيت تغيّر النقاط الافتراضية لكل فقرة، عدّل حقل `points` بكل عنصر بالملفات.
- المكتبة المستخدمة (`Baileys`) غير رسمية وتعتمد على بروتوكول واتساب مباشرة
  (بدون متصفح)، فيه احتمال ضئيل لحظر الرقم إذا استخدمته بشكل مكثف جداً أو
  مخالف لسياسات واتساب، لذلك يفضل استخدام رقم ثانوي كما تم الاتفاق.
- خلي البوت شغال بجهاز أو جوال متصل بالنت باستمرار (لابتوب، أو جوال بـ
  Termux مع `termux-wake-lock`)، لأنه لو سكرت الاتصال لازم يعيد الربط.
- لو المنشن (@) بالنتيجة النهائية طلع رقم غريب أو ما اشتغل، جرب أمر `ايديي`
  بنفس القروب. لو طلع آيدي شكله `...@lid` بدل رقم جوال عادي، فهذا نظام
  خصوصية جديد فعّله واتساب لبعض القروبات، ومو خطأ بالبوت — بهذي الحالة
  الاسم النصي جنب المنشن (اللي نعرضه دايماً كخطة احتياطية) هو المرجع الأكيد.
